# SIM-06 -- Section 70B

**Act I · Forensics · Hard**

## The brief

Forty documents, four incompatible numbering schemes, no index. A
quarterly review has been rebuilt from scratch four times because nobody can
hold all four schemes in their head at once. Somebody can.

## What you must do

Find the document referenced from all four schemes, the longest
revision chain, the department with delegated single-reviewer sign-off, and the
eight places reachable without logging in.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

```console
unzip vec-SIM-06-player.zip -d SIM-06
cd SIM-06/artifacts && ls
```
