# SIM-15 -- Tape Vault

**Act II · Forensics · Medium**

## The brief

A backup appliance wrote its index to a tape and then the appliance
was decommissioned. The tape was kept. The vendor's framing reference for the
container was kept with it.

## What you must do

Recover which files were committed to the tape, and in what
order, from tape/index.tvt.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

```console
unzip vec-SIM-15-player.zip -d SIM-15
cd SIM-15/artifacts && ls
```
