# SIM-35 -- NACH

**Act VIII · Forensics · Insane**

## The brief

A network capture from the night of the first anomalous approval,
and a scanned folder of shredded procurement documents. Nobody steals money on
the way into a power company.

## What you must do

Identify the insider, recover the money trail, and find the
planted error.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

```console
unzip vec-SIM-35-player.zip -d SIM-35
cd SIM-35/artifacts && ls
```
