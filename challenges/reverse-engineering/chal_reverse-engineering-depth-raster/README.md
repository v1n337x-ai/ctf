# SIM-17 -- Depth Raster

**Act II · Reverse Engineering · Hard**

## The brief

A survey instrument wrote a 1-bit-per-pixel raster and then the
instrument was lost. The raster was recovered from its storage, and the vendor's
raster reference for the encoding was kept with the survey notes.

## What you must do

Recover what the raster shows from capture/depth.rstr.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

```console
unzip vec-SIM-17-player.zip -d SIM-17
cd SIM-17/artifacts && ls
```
