# SIM-19 -- Dispatch Log

**Act II · Reverse Engineering · Medium**

## The brief

A dispatch station logged a night shift as a trace for its own small
register machine. The machine's ISA reference was kept with the station. The
trace was not, and the shift supervisor wants to know what the machine was
holding when it stopped.

## What you must do

Execute the trace in capture/shift.dlog and report what the
station's answer registers held when it halted.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

cd SIM-19/artifacts && ls
