# SIM-16 -- Bit Vault

**Act II · Forensics · Hard**

## The brief

A hardware logger was pulled from a decommissioned unit. It wrote
its output as a stream of 9-bit words packed into bytes, and the vendor's word
reference for that encoding was kept with the unit.

## What you must do

Recover what the logger recorded from
capture/word_stream.bin.

## Getting started

Work through the `artifacts/` directory. Everything you need is there; nothing needs to be running.

```console
unzip vec-SIM-16-player.zip -d SIM-16
cd SIM-16/artifacts && ls
```
